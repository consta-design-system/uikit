```tsx
import {
  Transition,
  TransitionGroup,
  TransitionGroupNode,
} from '@consta/uikit/Transition';
```

Компонент `Transition` используется для анимации переходов между состояниями mount/unmount компонента. `TransitionGroup` и `TransitionGroupNode` используются для анимирования переходов компонентов в группе.
