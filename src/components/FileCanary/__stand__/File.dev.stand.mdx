## Обзор

Компонент `File` используется для отображения иконки файла с указанием его расширения и размера. Расширения разделены на логические группы, определяющие цвет компонента в группе и его иконку. Для некоторых специфичных расширений иконка внутри группы может отличаться.

## Импорт

```tsx
import { File } from '@consta/uikit/FileCanary';
```

## Пример использования

```tsx
import React from 'react';
import { File } from '@consta/uikit/FileCanary';

const App = () => {
  return <File extension="doc" />;
};
```

## Свойства

| Свойство                         | Тип          | По умолчанию | Описание                              |
| -------------------------------- | ------------ | ------------ | ------------------------------------- |
| [`extension`](#расширение-файла) | `string`     | -            | Расширение файла, определяющее иконку |
| [`size?`](#размер-иконки)        | `'m' \| 's'` | `'m'`        | Размер иконки                         |
| `className?`                     | `string`     | -            | Дополнительный CSS-класс              |

## Содержимое

### Расширение файла

Свойство `extension` определяет иконку файла в зависимости от его расширения. Если указанное расширение не поддерживается, отображается иконка со знаком вопроса и введенное значение расширения.

## Кастомизация

Компонент `File` можно  кастомизировать двумя способами:

1. **Через CSS-переменные** – изменить цвета существующих групп без создания нового компонента.
2. **Через конфиг** – создать собственную версию компонента с другими иконками и цветами для конкретных расширений.

### Переопределение цвета группы

Для каждой группы файлов существуют специальные CSS-переменные с суффиксом `-override`. Задавая их, вы можете переопределить цвет для всех экземпляров компонента внутри области действия переменной.

**Полный список переменных для переопределения:**

| Переменная для переопределения       | Группа      |
| ------------------------------------ | ----------- |
| `--file-color-code-override`         | Код         |
| `--file-color-font-override`         | Шрифт       |
| `--file-color-disk-override`         | Образ       |
| `--file-color-executive-override`    | Исполняемый |
| `--file-color-config-override`       | Конфиг      |
| `--file-color-database-override`     | БД          |
| `--file-color-presentation-override` | Презентация |
| `--file-color-table-override`        | Таблица     |
| `--file-color-document-override`     | Документ    |
| `--file-color-pdf-override`          | PDF         |
| `--file-color-audio-override`        | Аудио       |
| `--file-color-image-override`        | Изображение |
| `--file-color-video-override`        | Видео       |
| `--file-color-mail-override`         | Почта       |
| `--file-color-scheme-override`       | Схема       |
| `--file-color-archive-override`      | Архив       |

### Создание собственного компонента

Если вам нужно не только изменить цвет, но и задать другие иконки или цвета для конкретных расширений, вы можете создать собственный конфиг и на его основе сгенерировать новый компонент.

#### Структура конфига

Конфиг представляет собой объект, где ключ - расширение файла (строка), а значение - объект с двумя обязательными полями:

- `color` — цвет иконки (строка, любой формат CSS)
- `icon` — компонент иконки из `@consta/icons`

```ts
import { FileConfig } from '@consta/uikit/FileCanary';
import { IconFilePDF } from '@consta/icons/IconFilePDF';
import { IconFileDocument } from '@consta/icons/IconFileDocument';

const config = {
  pdf: {
    color: '#C62828',
    icon: IconFilePDF,
  },
  doc: {
    color: '#016BDC',
    icon: IconFileDocument,
  },
};
```

#### Генератор компонента

Это функция, которая принимает конфиг и возвращает готовый компонент `File`, использующий этот конфиг.

```ts
import { fileGenerator } from '@consta/uikit/FileCanary';
import { defaultConfig } from '@consta/uikit/FileCanary';
import { IconFileConfig } from '@consta/icons';

const myConfig = {...defaultConfig, ...{ 'xyz':  color: 'red', icon: IconFileConfig }};

const MyFile = fileGenerator(myConfig);
```
