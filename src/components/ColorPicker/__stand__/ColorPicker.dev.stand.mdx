## Обзор

Компонент ColorPicker предназначен для выбора цвета.

## Импорт

```jsx
import { ColorPicker } from '@consta/uikit/ColorPicker';
```

## Модель цвета

Модель цвета необходима для унификации работы с цветами, обеспечивая возможность конвертации между различными цветовыми формами и упрощая выполнение операций над цветами.

```ts
type HsvaColor = {
  h: number;
  s: number;
  v: number;
  a: number;
};

type ColorModel<T> = {
  defaultColor: T;
  toHsva: (color: T) => HsvaColor;
  fromHsva: (hsva: HsvaColor) => T;
  equal: (first: T, second: T) => boolean;
};
```

Библиотека предоставляет несколько моделей цвета:

```ts
import {
  hexModel, // '#rrggbb'
  hexAlphaModel, // '#rrggbbaa'
  rgbModel, // { r, g, b }
  rgbStringModel, // 'rgb(r, g, b)'
  rgbaModel, // { r, g, b, a }
  rgbaStringModel, // 'rgba(r, g, b, a)'
  hslModel, // { h, s, l }
  hslStringModel, // 'hsl(h, s, l)'
  hslaModel, // { h, s, l, a }
  hslaStringModel, // 'hsla(h, s, l, a)'
  hsvModel, // { h, s, v }
  hsvStringModel, // 'hsv(h, s, v)'
  hsvaModel, // { h, s, v, a }
  hsvaStringModel, // 'hsva(h, s, v, a)'
} from '@consta/uikit/ColorPicker';
```

## Якорь

Вы можете указать якорь для попапа цвета с помощью свойства `anchorRef`. На якорь будут назначены события клика. Если не обходимо позиционировать попап от одного элемента а события назначить на другой, то укажите `controlRef`.

<MdxTabs>

<ColorPickerExampleAnchor />

```tsx
import { Button } from '@consta/uikit/Button';
import { ColorPicker, hexModel } from '@consta/uikit/ColorPicker';

export const ColorPickerExampleAnchor = () => {
  const [color, setColor] = React.useState(hexModel.defaultColor);
  const anchorRef = React.useRef(null);
  return (
    <>
      <Button label={color} ref={anchorRef} />
      <ColorPicker
        value={color}
        model={hexModel}
        onChange={setColor}
        anchorRef={anchorRef}
      />
    </>
  );
};
```

</MdxTabs>
